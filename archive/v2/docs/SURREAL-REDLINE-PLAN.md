# AlphaLens 超现实重构规划（SURREAL-REDLINE）

- 日期：2026-11-19
- 输入：用户要求「以之前提供的 UI 模板网站为基础框架 + 超现实主义风格（大胆视觉、梦幻色彩、扭曲排版、想象力图形组合），布局清晰可导航，保持艺术表现力」
- 前置约束：用户刚批评当前版「不是人用的东西」——假异动、坏时间戳、开发者黑话披露条、数据倾倒无判断。**本规划必须先修这些，再谈艺术。**

---

## 0. pstack 三行对齐

- **Target**：fiapp 骨架 + 超现实氛围层 + 人能用的信息架构。
- **Premise & Bottleneck**：超现实若施于数据数字＝重蹈「不是人用的」覆辙。病根是数据倾倒，不是视觉不够花。
- **Smallest Leap**：先修诚实性三宗罪（假事件/坏时间/黑话），再做氛围层超现实，数据层保持钢铁可读。

## 3. 核心设计决策：超现实的落地边界（最关键，请确认）

**超现实 ≠ 把数字也扭曲。** 采用「双平面」策略：

| 平面 | 处理 | 具体内容 |
|---|---|---|
| **氛围层（可超现实）** | 大胆、梦幻、扭曲、想象力 | 背景：流动渐变 mesh + 颗粒噪点 + 漂浮轨道图形；标题：超大字号/负字距/错位叠印；卡片：不规则圆角/轻微旋转叠层/玻璃折射边；转场：流体式位移；装饰：月相/等值线/星座连线 SVG |
| **数据层（必须克制）** | 钢铁般可读 | 所有价格/涨跌/市值/表格数字：等宽 tabular-nums、右对齐、固定色板（红涨绿跌）；榜单行结构稳定；披露条移出首屏 |

**为什么这样分**：超现实负责"记住这个产品"，数据层负责"每天真的能用"。两者混在一起就会变成你骂的东西。

## 4. Fix 方案（分阶段）

### Gate A — 诚实性修复（不做完不动视觉）
- A1 事件时间戳：从 `time` 字段正确解析 `HH:MM:SS`，无真实时间则显示「快照」不编造
- A2 事件语义：删掉"数据源切换"假异动，只保留真实逐轮变化；首轮不报警
- A3 时间统一：顶栏只显示一个「数据截至 YYYY-MM-DD HH:MM」+ 状态徽章，删掉矛盾双时间
- A4 披露条：改为可折叠的「数据口径 ⓘ」，默认收起，点开才看详情
- A5 「24H 涨跌」→「今日涨跌」

### Gate B — 超现实氛围层（fiapp 骨架不变）
- B1 **配色**：以浅色为底（守住"全站浅色"红线），引入 vibedesign 冷蓝 `#7fb2ff/#3a5fd8` 做**氛围渐变**，暖光 `#ffe2a0/#ffad66` 做点缀，不进数据数字
- B2 **背景**：CSS mesh-gradient + 固定噪点 overlay（内联 SVG data URI，零外链）+ 缓慢漂浮的抽象轨道 SVG
- B3 **字体层级**：标题换有性格的字体栈（系统可用的 `Georgia/Serif` 做超大标题 + 无衬线正文），数字仍等宽
- B4 **卡片**：不等圆角（外 14px / 内 6px）、轻微错位叠层、hover 时 spotlight 边框跟随光标
- B5 **装饰图形**：页面角落放 3-4 个超现实 SVG 符号（眼睛/轨道/漂浮几何/星座连线），纯装饰 `aria-hidden`
- B6 **转场**：视图切换用流体式 opacity+transform（沿用已建的动效 token）

### Gate C — 信息架构（从数据倾倒到回答问题）
- C1 顶部加「今日速览」一句话：用真实数据生成（如「市场偏冷，资金观望；3 只标的异动」）
- C2 板块重排为三段：**先看市场 → 再看异动 → 最后深挖**（当前 11 板块平铺）
- C3 事件区移到更靠前，因为它是"发生了什么"的答案
- C4 保留全部 45 只可点进详情、榜单自动重排、十年图十字光标等已验证功能

### Gate D — 验收
- D1 冻结三 sha 不变、verify.js 59/0、`file://` 双击可用、无 CDN
- D2 UI 验收脚本扩展：新增「事件时间戳格式正确」「无假异动文案」「披露条默认收起」「超现实装饰不遮挡数据」断言
- D3 独立验证器对抗复核（pstack 双 Tab）
- D4 桌面 1440 + 移动 390 实机截图

## 5. 明确不做（避免又走偏）

- ❌ 液态玻璃套娃 / 镭射卡片 / 冲击波 / ASCII 抖色——营销站语汇，进金融终端就是噪音（redesign skill 也明确反对"AI 味垃圾"）
- ❌ 扭曲数据数字 / 旋转表格 / 梦幻色涨跌——红涨绿跌是用户拍板红线
- ❌ 引入任何 CDN 字体/图标库——`file://` 离线红线
- ❌ 重构数据层 / 动 core.js / 改冻结原版
