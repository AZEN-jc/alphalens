## 1. 项目简介与核心痛点

AlphaLens v3.1 不是行情看板，而是**有输入、有算法计算、有四维独立诊断结论**的垂直持仓体检工具，解决个人投资者真实存在却难以一站式算清的两大痛点：

- **痛点 A｜ETF 假分散（A 股 & 美股科技 QDII）**：同时买沪深300 + 上证50 + 银行ETF，或同时买纳指 + 标普500 + 纳指科技，看似分散，穿透底层前十大重仓并做美股/港股代码别名归一化后，发现底层高度重合于同一批龙头股（招行/茅台，或英伟达/苹果/谷歌/微软）。
- **痛点 B｜高股息吃息真相**：高股息不等于真收益。按**除权除息日**统计的连续分红是否稳定？用**严格不复权日线**核验的填权胜率、平均填权天数与已填/未填样本数如何？结合持股周期红利税（财税〔2015〕101 号文）情景测算后，相对定存/国债基准真实息差是多少？

## 2. v3.1 核心功能与算法升级

**模块 A｜组合持仓穿透体检**
- **36 只标的池 + 跨市场 QDII/科技覆盖**：21 只场内 ETF（含美股 QDII、港股 QDII、A 股科技、宽基、红利、行业、商品）+ 15 只高股息 A 股，均以人民币计价并天然共享 A 股交易日历。
- **美股/港股重仓别名归一化**：将不同 QDII 季报披露的 `NVDA / NVIDIA / 英伟达`、`GOOGL / GOOG / 谷歌-A / 谷歌-C`、`00700 / 0700 / 腾讯控股` 等自动归一化并合并同源占比，防止同一只底层股票被拆分成多项而漏报重合。
- **统一前复权（`qfq`）+ 共同回测时间窗口**：全量 36 只标的统一抓取近 3 年前复权日线，前端支持一键切换 **近 1 年（250 交易日）**（默认）与 **近 3 年（全量对齐）**，两张手写 SVG 图表旁显式标出对齐起止日期、共同交易日数与前复权口径，确保不同组合公平对比。
- **四维独立风险诊断（`evaluatePortfolioRisk`）**：告别单一 HIGH/MEDIUM/LOW “一刀切”标签，将组合体检拆为四个独立维度并同步导出至 Markdown 报告：
  1. **集中度**（单一底层最大权重）
  2. **重仓重合**（重合重仓只数与合计权重）
  3. **资产相关性**（日收益率皮尔逊相关性矩阵非对角均值）
  4. **回撤与波动**（共同窗口内最大回撤 MDD 与年化波动率）

**模块 B｜高股息吃息真相**
- **除权日口径连续分红**：15 只高股息 A 股改按有效分红记录的**除权除息日（`exDate`）所在年份**去重倒序统计连续派息年数，按时间正序呈现近 10 次分红与填权时间轴。
- **不复权填权核验与样本透明化**：严格基于近 10 年**不复权日线（`adjust=""`）**校验 `close ≥ 除权前收盘`，显式输出 `filledCount / unfilledCount / totalEvents`，界面统一展示为 `平均 X 天（已填 M / 未填 N）`（全部未填时显示 `--（未填 N 次）`）。
- **历史股息税后收益情景测算**：依据财政部、税务总局、证监会**财税〔2015〕101 号文**（持股 ≤1 个月 20%、1 个月–1 年 10%、超 1 年暂免），提示“实际税负按单笔买入批次在卖出转让时结算，本模块为基于历史股息率的情景估算”。

**工程与交互特性**
- **真正单文件内联交付**：构建时将 `analytics.js`、`live.js` 与 `analysis_data.json` 全部内联进 `index.html`（及 `index_alphalens_v3_live.html`），零外部 `<script src>`，单独拷贝 `index.html` 至任意孤立目录即可 100% 离线运行。
- **腾讯实时行情与精确计数徽标**：`live.js` 以“成功解析 ≥1 只标的有效数值”作为成功判据，避免停盘/周末误判降频；修复深市 `159xxx` ETF 前缀映射；顶栏精确展示 `LIVE N/36`，未获实时价行保留离线价并标注 `快照`，6 秒全部超时降级 `SNAPSHOT · 离线快照`。
- **流畅编辑与持久化**：新增持仓立即写入 `localStorage`；编辑金额时仅就地更新占比文本节点与右侧诊断，输入框永不失焦。

## 3. 快速开始（3 种方式）

```bash
# 方式一：零配置体验 —— 浏览器双击根目录 index.html
#         （真正单文件，可单独复制到任意目录双击打开）

# 方式二：刷新近 3 年统一前复权数据并重建单文件
python fetch_holdings_dividend.py   # 抓取 36 标的持仓/3年qfq日线/10年不复权分红填权
python build_v3.py                  # 内联 analytics.js + live.js + 数据，输出真单文件

# 方式三：跨平台自动化验收（含孤立单文件测试）
node verify_v3.mjs                  # 覆盖数据口径、归一化、四维诊断、交互焦点与孤立运行
```

> **GitHub Pages 在线体验开启指引**：Fork 或推送本仓库至 GitHub 后，进入仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)` 并保存；约 1 分钟后即可通过 `https://<你的用户名>.github.io/alphalens/` 直接在线打开（根目录 `index.html` 即为完整单文件入口，无需任何构建流水线）。

## 5. 数据口径与透明度说明

| 数据 | 来源与口径 |
|---|---|
| ETF 前十大持仓 | AKShare `fund_portfolio_hold_em`（最新季报，美股/港股重仓代码别名归一化） |
| 基金概况 / 费率 | AKShare `fund_overview_em(symbol=code)`（管理费 + 托管费，查不到为 `null` 显示 `--`） |
| 回测与相关性日线 | 统一近 3 年**前复权（`qfq`）**收盘价（ETF 优先 `fund_etf_hist_em`、限流自动回退 `stock_zh_a_hist_tx`；个股 `stock_zh_a_daily`） |
| 个股现金分红 | AKShare `stock_history_dividend_detail`（近 10 年，仅「实施」且派息 > 0，按除权除息日年份统计） |
| 填权天数核验 | 近 10 年**严格不复权（`adjust=""`）**日线，口径 `close ≥ 除权前收盘`，绝不与前复权回测混用 |
| 实时行情 | 腾讯财经 `qt.gtimg.cn` JSONP，精确计数 `LIVE N/36`，6 秒超时降级 `SNAPSHOT` |

**诚实标识**（缺失绝不估算）：
- `NO_EQUITY_HOLDINGS` — 商品 ETF 无股票持仓（如黄金ETF 518880），穿透时识别为独立大类资产
- `FETCH_ERROR` — 单只标的接口暂时失败，不中断整批构建
- `SNAPSHOT` / 行内 `快照` — 断网、超时或单只未取到实时价时明确标出使用离线快照
- `--` — 字段缺失或样本为 0，绝不以 0.00% 误导

> ETF 穿透仅基于公开季报前十大重仓，覆盖率不等于全仓；历史股息与回测数据仅供个人持仓诊断参考，不构成投资建议。

├── assets/fonts/               # 本地字体资源
