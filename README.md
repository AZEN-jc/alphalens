## 1. 项目定位与核心解决的痛点

AlphaLens v5.0 面向**金融科技毕业设计答辩**与**普通个人投资者实战诊断**双重场景，借鉴 **TradingView / Koyfin / Linear / Apple 股市** 的克制交互与纸墨浅/深双色体系，构建了「**持仓穿透诊断 → 经典量化度量 → 智能去重优化 → A/B 同屏对照 → 论文素材导出**」的完整分析闭环：

- **痛点 A｜ETF 假分散（A 股 & 美港科技 QDII）**：同时买入沪深300 + 上证50 + 银行 ETF，或同时持有纳指 + 标普500 + 纳指科技，表面看似分散，穿透底层前十大重仓并完成美/港股代码别名归一化后，暴露出高度重合的同一批龙头股与高走势相关性。
- **痛点 B｜查出问题后如何科学调仓**：仅指出“重合度高”不够，系统引入 **HHI 赫芬达尔集中度、有效独立持仓数 $N_{\text{eff}}$、年化收益（CAGR）、夏普比率、卡玛比率** 与 **双模式智能去重降险引擎（仅调权重风险平价 / 引入低相关资产）**，一键呈现调仓前后对比并支持应用/撤销。
- **痛点 C｜高股息吃息真相**：高股息不等于真收益。按**除权除息日**统计近 10 年连续分红，严格采用**不复权日线（`adjust=""`）**核验填权胜率与平均填权天数，结合**财税〔2015〕101 号文**分档红利税测算相对基准真实息差。

## 2. v5.0 核心特性总览

### ① 克制四舱主页 + 立体可视化引擎
- **顶部配置栏**：5 套经典对照组合一键切换、总本金实时无损缩放（`1万 / 5万 / 10万 / 50万` + 一键均分）、`⌘K` 快捷搜索面板与手机端底部 Dock + 上拉抽屉（`390px` 零横向溢出）。
- **资金穿透舞台（3D / 2D 双模）**：原生 Canvas 2D 透视景深柱体与 2D 平面流向图无缝切换，支持点击基金/股票节点锁定资金通道；合并穿透前 15 总览支持「**全部 / 仅看撞车**」过滤、关键词搜索与点击反查来源基金。
- **实体地质沙盘块（`X × Y × Z` 三维坐标系）**：采用非线性高斯山峰 + 翠绿安全洼地 + 4 面闭合地质切壁 + 厚实底座 + 逐面片 3D 等高环（`Z = 20 / 40 / 60 / 80`）+ 三枚垂直标杆，支持 360° 拖拽、滚轮缩放、放大剖面弹窗及「低角看峰 / 高空俯瞰 / 导出白底 PNG」。
- **核心体检与经典量化条**：四维独立风险评级（单股占比 / 基金重合 / 走势联动 / 历史回撤）+ 5 项经典量化指标条（`CAGR` / `夏普比率` / `卡玛比率` / `相对沪深300超额` / `有效持仓数 N_eff`）+ Linear 级数字缓动过渡（支持静谧模式瞬切）。

### ② TradingView / Koyfin 级交互式进阶图表
- **交互式净值与回撤曲线**：支持叠加/隐藏 **沪深300ETF（`510300`）** 同期基准曲线，鼠标滑动触发垂直十字准星与悬浮 HUD，实时读出任意交易日的组合净值、回撤、基准收益与超额收益；支持「近 1 年（250 日）/ 近 3 年（全量对齐）」一键切换。
- **交互式相关性矩阵**：悬停任意方格高亮对应行/列标签，底部即时输出大白话相关性诊断。

### ③ 毕业设计答辩与论文写作四件套（按需弹层，主页零堆砌）
1. **✦ 智能优化弹窗**：支持「仅调权重（反波动率 × 反相关性风险平价）」与「引入低相关资产（跨大类去重降险）」双模式，展示 6 维指标前后对比箭头与依据清单，可一键应用（支持 Toast 撤销）或直接发送至 A/B 对比台。
2. **组合 A / B 同屏对照实验台**：任意两套组合（当前组合 / 智能优化方案 / 5 套预设）同屏展示共同交易日归一化双净值曲线 + 8 项核心指标胜出高亮对照表，支持导出高清 PNG。
3. **算法公式与数据口径学术说明书**：集中展示底层穿透归因、HHI & $N_{\text{eff}}$、CAGR/Sharpe/Calmar、风险平价配权、不复权填权判定及财税 101 号文税率公式。
4. **论文素材与组合快照导出**：3D 地质沙盘 / 净值图 / 相关性矩阵 / A-B 对比图均支持一键导出 **2× DPR 论文白底高清 PNG**；支持 Markdown 体检报告、JSON 快照导入导出、`#p=` URL 状态分享链接及打印/PDF 排版。

### ④ 长期产品演进预留接口（P1 / P2 Architecture Hooks）
- `AlphaLensAnalytics.registerStrategyHook(name, fn)`：标准策略插件注册口，后续可零侵入接入多因子/马科维茨均值方差/自定义再平衡算法；
- `serializePortfolioState(state)` / `deserializePortfolioState(token, assetsMap)`：UTF-8 安全 Base64URL 状态序列化契约，支撑 URL 分享与外部组合导入。

## 5. 数据口径与诚实标识

| 数据项 | 来源与口径 |
|---|---|
| ETF 前十大持仓 | AKShare `fund_portfolio_hold_em`（最新季报，美股/港股代码别名归一化） |
| 回测与相关性日线 | 统一近 3 年**前复权（`qfq`）**收盘价，共同交易日严格对齐 |
| 基准与无风险利率 | 沪深300ETF（`510300`）同期前复权净值；夏普无风险利率 $r_f = 2.0\%$ |
| 个股分红与填权核验 | 近 10 年除权除息日口径；**严格不复权（`adjust=""`）**校验 `close ≥ 除权前收盘` |
| 实时行情 | 腾讯财经 `qt.gtimg.cn` JSONP，精确计数 `LIVE N/36`，6 秒超时降级 `SNAPSHOT` |

> ETF 穿透基于公开季报前十大重仓，覆盖率不等于全仓；历史收益、股息与优化测算仅供学术研究与个人诊断参考，不构成投资建议。
